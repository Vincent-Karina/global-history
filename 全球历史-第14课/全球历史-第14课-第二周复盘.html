二、机制地图：一条主链 + 三把尺子

主链（要能一口气复述）

环节 发生了什么 考古上看什么 边界（别过度推）
① 剩余与集聚 农业剩余可储存、人口变密 仓储、聚落规模与密度 大 ≠ 城；恰塔霍裕克很密，但缺公共机构
② 专家 一部分人不全靠种地生活 作坊、标准化产品（如斜沿碗）、工具专精 专精可以是兼职、季节性
③ 纪念性机构 神庙、王权、仪式中心把劳动组织起来 平台、神庙区（Eanna/Anu）、王陵 纪念建筑 ≠ 专制；非国家社会也能建
④ 行政记录 追踪谁交了什么、谁欠了什么 筹码、封泥球、圆筒印、泥板、标签、石权 有记录技术 ≠ 已垄断暴力
⑤ 抽取 + 强制 + 管辖 贡赋/劳役、强制手段、领土与人口主张叠在一起 聚落等级、暴力痕迹、精英丧葬差异 单项不足为证；看证据束

这是教学因果链，不是普世进化阶梯：各地可以跳步、倒序、停在某环，也可以崩解回去。

三把尺子

尺子 问的是 来源要点 用法提醒
城市：Childe 诊断项（约10条） 规模密度、全职专家、剩余集中、纪念建筑、统治阶层、文字、科学、艺术、远程贸易、超血缘归属 Childe 1950 The Urban Revolution 当工具箱，不当一票否决；缺项要解释

五、深挖要点（5）

要点 1：「三件套」拆开看——城市、国家、文字可以不同步

  • 有城未必有文字：印度河城镇规划与标准化极强，符号却未破译、是否「文字」仍争。
  • 有记录未必有强国家：筹码、封印、计量可以服务神庙、城邦机构或网络协调。
  • 有王权未必有大城：埃及早期以沿河节点与陵墓仪式景观显示权力，「大城市」形态反而不突出。 带走一句：三者是强相关，不是同时打包到货。

要点 2：跨案例完整因果链——「仓库 → 封印 → 泥板」

两河路径最清楚地把「行政需求 → 书写」拍成慢镜头：剩余集中到神庙/机构仓储 → 斜沿碗等量产器物显示劳动编排 → 圆筒印与封泥认证「谁封的、谁负责」→ 封泥球把筹码封闭并在外面摘要 → 扁平泥板直接画写清单与数量（约前3400–前3000 量级）→ 楔形文字行政系统。最早文本主流是清单、度量、职事（Englund 等），文学传统更晚。埃及标签路径动机相近（王室流通、仓储、义务），形态不同。 批评要带上：Schmandt-Besserat 的「筹码 → 文字」直线叙事是好教学模型，但被批评过度线性化，须叠加泥板语料本身的证据。

要点 3：南北双早期——「单点发明 + 扩散箭头」为什么要放弃

泰尔布拉克 LC2–LC3（约前4100–前3600）已有大规模城市化与纪念性（Oates；Ur 等综合），时间上可与南部对话。乌鲁克晚期确有远距据点与风格扩散，Algaze 的「世界体系」能解释原料—成品不对称；但把它读成现代殖民帝国缩小版，会低估北方与边缘的地方能动。地图应画双早期 + 互动，不是一个发明点。

要点 4：国家怎么认——证据束，而不是单一指标

指标 能说明 不能说明
纪念性建筑 劳动动员能力 中央专制
聚落等级 协调与抽取半径 一定是国家（贸易/仪式中心也能成层级）
印章/封泥/计量/文字 行政技术 已垄断暴力
暴力痕迹、城墙 强制与防御可见度 有墙 = 有国家
精英丧葬差异 等级可见化 常设官僚
规则：组合看、找缺项、解释缺项。

要点 5：理论是透镜，不是答案——多因合用并带批评

理论 照亮什么 主要批评
Wittfogel「水利专制」（1957 Oriental Despotism） 灌溉与组织能力相关 灌溉可先于或独立于强国家；埃及等被漫画化
Carneiro 环境限制 + 战争整合（1970，Science） 走不掉的河谷/海岸里，冲突促成整合 非充分条件；无强封闭处也能复杂化
Algaze 贸易 / 世界体系（1993 The Uruk World System） 远程交换与中心化 低估地方能动；贸易也可瓦解中心
仪式 / 意识形态优先 权力需要叙事与合法化 仪式 ≠ 国家；纪念建筑可在非国家社会出现
带走：每个案例通常是两三种机制叠加，单因论在至少一个案例上会翻车。

六、常见误读纠偏

误读 更接近证据的说法
耶利哥 / 恰塔霍裕克是第一批城市 大型村落 / 原城市；缺常设公共机构与专家包
城市只在乌鲁克发明一次再扩散 泰尔布拉克等显示北方大致同期城市化；南北互动
城市 = 国家 = 文字，同时到达 强相关但可不同步；印度河、埃及各是反例的一面
文字是为写史诗 / 神话发明的 近东最早文本主流是行政清单；文学后到
有城墙就有国家 城墙说明防御与动员；酋邦、城镇也可有墙
没宫殿、没文字就没国家 缺宫殿肖像 ≠ 无复杂管理；印章、计量、标准化也是行政证据
治水必然产生专制 Wittfogel 须批评；灌溉与国家是多因关系
乌鲁克据点 = 现代殖民帝国 有远距据点与风格扩散，地方能动同样重要
印度河「神秘消失」 约前1900 后一体化减弱，地方化/东移；气候、河道、贸易网变迁等假说并存
中国「五千年一条直线」 多区域并行与互动；甲骨是成熟书写硬证据，陶文/刻符仍争
早 = 高级，可以排行 时钟不同、配方不同；对照机制，不排名次

七、一句话记住

剩余养出专家，机构组织劳动，记录把义务外置；当抽取、强制与管辖叠在一起，才叫国家——城市、国家、文字强相关却可不同步，六条路径时钟不同、配方不同，不排名。

八、今天可动手试一件事

「权力怎样被看见」六格卡（15–20 分钟） 1. 画 2×3 六格：耶利哥/恰塔霍裕克、乌鲁克、泰尔布拉克、埃及、印度河、中国早期。 2. 每格只写三行：剩余存在哪儿？谁组织劳动？用什么记录或认证？（不知道就写「待查」，不编年份。） 3. 用第五节证据束给每格打 ✓ / △ / ✗，判断它更像「复杂酋邦 / 原城市」还是「早期国家倾向」。 4. 圈出你最没把握的一格，写下需要什么证据才能改判。 5. 最后写一个给下周的问题：当多个城市国家同时存在，它们之间靠什么连起来——战争、婚姻、贸易还是书信？
